# 07.1\_TEST CASE CATALOG — CHAT (MVP)

## Legend

* **Priority**: P1 (must), P2 (should), P3 (nice)
* **Type**: ✅ Positive / ❌ Negative
* **Events**: domain events emitted on success
* **ErrCode**: canonical error code on failure (see 04 catalog)

## A) Start Conversation

| ID             | Title                                         | Type | Priority |
| -------------- | --------------------------------------------- | ---- | -------- |
| CHAT-START-001 | Start with default title when empty/omitted   | ✅    | P1       |
| CHAT-START-002 | Start with valid user-provided title (1..200) | ✅    | P1       |
| CHAT-START-003 | Reject invalid ownerId (empty Guid)           | ❌    | P1       |
| CHAT-START-004 | Reject invalid title (0 after trim)           | ❌    | P1       |
| CHAT-START-005 | Reject title > 200 chars                      | ❌    | P1       |

**Preconditions (common):** none.
**Steps / Expected:**

* **001**: Call Start(ownerId=valid, title=null/whitespace).
  **Then** status=Active, title="New chat {shortId}", isDefaultTitle=true, messageCount=0.
  **Event**: `ConversationStarted(conversationId, ownerId, title)`.
* **002**: Start(ownerId=valid, title="  My Title  ").
  **Then** title="My Title", isDefaultTitle=false, status=Active.
  **Event**: `ConversationStarted(...)`.
* **003**: Start(ownerId=Guid.Empty).
  **Then** reject **CHAT.CONVERSATION.OWNER\_REQUIRED**.
* **004**: Start(title="   ").
  **Then** reject **CHAT.CONVERSATION.TITLE\_INVALID**.
* **005**: Start(title length=201).
  **Then** reject **CHAT.CONVERSATION.TITLE\_INVALID**.

## B) Append Message

| ID              | Title                                                 | Type | Priority |
| --------------- | ----------------------------------------------------- | ---- | -------- |
| CHAT-APPEND-001 | First message: user → success                         | ✅    | P1       |
| CHAT-APPEND-002 | First message: assistant → reject                     | ❌    | P1       |
| CHAT-APPEND-003 | Alternation: user → assistant                         | ✅    | P1       |
| CHAT-APPEND-004 | Alternation: assistant → user                         | ✅    | P1       |
| CHAT-APPEND-005 | Consecutive assistant → reject                        | ❌    | P1       |
| CHAT-APPEND-006 | Consecutive user → allowed                            | ✅    | P2       |
| CHAT-APPEND-007 | Reject when conversation Completed                    | ❌    | P1       |
| CHAT-APPEND-008 | Reject content length = 0                             | ❌    | P1       |
| CHAT-APPEND-009 | Reject content length > 100,000                       | ❌    | P1       |
| CHAT-APPEND-010 | Boundary: content length = 1                          | ✅    | P1       |
| CHAT-APPEND-011 | Boundary: content length = 100,000                    | ✅    | P1       |
| CHAT-APPEND-012 | Boundary: messageCount=9,999 → allow (becomes 10,000) | ✅    | P1       |
| CHAT-APPEND-013 | Boundary: messageCount=10,000 → reject                | ❌    | P1       |
| CHAT-APPEND-014 | Sequence contiguity maintained                        | ✅    | P2       |

**Preconditions:**

* For 001–006, 010–014: `conversation` Active.
* For 007: `conversation` Completed.

**Steps / Expected (highlights):**

* **001**: Append(role=user, content len in \[1..100k]) on empty convo.
  **Then** sequence=1, messageCount=1, occurredAt set.
  **Event**: `MessageAppended(conversationId, messageId, 1, "user", preview(100), contentLen, occurredAt)`.
* **002**: Append(role=assistant) on empty convo → **CHAT.MESSAGE.FIRST\_MUST\_BE\_USER**.
* **003**: After a user message, append assistant → success; event raised.
* **004**: After assistant, append user → success; event raised.
* **005**: assistant followed by assistant → **CHAT.MESSAGE.TURN\_TAKING\_VIOLATION**.
* **006**: user followed by user → success (MVP allows).
* **007**: Any append on Completed → **CHAT.CONVERSATION.NOT\_ACTIVE**.
* **008**: content="" / whitespace → **CHAT.MESSAGE.CONTENT\_INVALID**.
* **009**: content length 100,001 → **CHAT.MESSAGE.CONTENT\_INVALID**.
* **010/011**: Content length boundary passes; event includes correct `contentLength` and preview truncated at 100.
* **012**: Current count=9,999 → append allowed; new count=10,000.
* **013**: Current count=10,000 → append rejected **CHAT.CONVERSATION.MESSAGE\_LIMIT\_EXCEEDED**.
* **014**: After multiple appends, assert `messages[i].sequence == i+1`.

## E) Event Payload Checks (cross-cutting)

| ID             | Title                                        | Applies To   | Type | Priority |
| -------------- | -------------------------------------------- | ------------ | ---- | -------- |
| CHAT-EVENT-001 | ConversationStarted payload correctness      | Start        | ✅    | P1       |
| CHAT-EVENT-002 | MessageAppended payload correctness          | Append       | ✅    | P1       |
| CHAT-EVENT-003 | ConversationTitleUpdated payload correctness | Update Title | ✅    | P2       |
| CHAT-EVENT-004 | ConversationCompleted payload correctness    | Complete     | ✅    | P1       |

**Expectations:**

* **Started**: `(conversationId!=default, ownerId!=default, title non-empty)`; exactly one event.
* **Appended**: `messageId!=default`, `sequence` equals new count, `role ∈ {user,assistant}`, `contentPreview.Length ≤ 100`, `contentLength == content.Length`, `occurredAt ≈ now`.
* **TitleUpdated**: carries `oldTitle`, `newTitle`, both within bounds.
* **Completed**: carries `messageCount` equal to final count.

> **Note**: No aggregateVersion in domain payload (MVP).

## G) Boundary & Fuzz Set (shared fixtures)

* **OwnerId**: valid GUID; invalid = `Guid.Empty`.
* **Title**:

    * Min valid: length=1 (e.g., `"A"`), Max valid: length=200.
    * Invalid: `""`, `"   "`, length=201.
    * Same-after-trim/case: `"  My Title  "` vs current `"my title"`.
* **Content**:

    * Min valid: 1 char, Max valid: 100,000 chars.
    * Invalid: 0 chars / whitespace-only, 100,001 chars.
    * Preview cases: length=100 exactly; length=101 (expect truncate to 100).
* **Counts**:

    * `messageCount` transitions: 0 → 1, 9,999 → 10,000 (allow), 10,000 → (reject next).
