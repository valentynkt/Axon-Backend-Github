## Key Concepts

**The Co-Pilot's Code**: Seven immutable principles guiding Axon development
**The Great Utility Shift**: Market transition from speculation to utility-driven demand
**Conversational Singularity**: Vision of natural on-chain interaction through AI
**Utility-as-a-Service**: B2B positioning as Solana ecosystem infrastructure

## Target Personas

**Primary**: "Nova" - Solana power users (top 2% driving 50%+ trading volume)
**Secondary**: Solana dApp developers seeking AI integration capabilities

## Strategic Positioning

Axon AI serves as foundational Solana infrastructure, not competing dApp:
- Intelligence Layer: Personalized on-chain insights and memory
- Action Layer: Safe, simulated transaction execution
- B2B API: `/intent` endpoint for developer ecosystem integration
