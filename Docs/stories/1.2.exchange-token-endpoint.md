# Story 1.2: Exchange Token Endpoint (Simplified)

## Status
Ready for Review

## Story
**As a** frontend developer,  
**I want** to exchange Dynamic.xyz JWT tokens for Axon user context,  
**so that** I can authenticate users with minimal backend complexity.

## Acceptance Criteria

1. Create single `ExchangeTokenEndpoint` at `POST /api/v1/auth/exchange`
2. Extract JWT from `Authorization: Bearer {token}` header
3. Call `DynamicAuthService.ValidateTokenAsync` to validate with Dynamic.xyz
4. Map Dynamic.xyz response to simple Axon user format
5. Return user context with wallet information
6. Use standard HTTP status codes (200, 401, 503)
7. No custom validation logic - full delegation to Dynamic.xyz
8. Simple error handling with generic messages

### Example Implementation
```csharp
public class ExchangeTokenEndpoint : Endpoint<EmptyRequest, ExchangeTokenResponse>
{
    private readonly DynamicAuthService _dynamicAuth;
    
    public override void Configure()
    {
        Post("/api/v1/auth/exchange");
        AllowAnonymous();
    }
    
    public override async Task HandleAsync(EmptyRequest _, CancellationToken ct)
    {
        var token = HttpContext.Request.Headers.Authorization
            .FirstOrDefault()?.Replace("Bearer ", "");
            
        if (string.IsNullOrEmpty(token))
        {
            await SendAsync(null, 401, ct);
            return;
        }
        
        var result = await _dynamicAuth.ValidateTokenAsync(token);
        
        if (result.IsFailure)
        {
            await SendAsync(null, result.Error.Code == "ServiceUnavailable" ? 503 : 401, ct);
            return;
        }
        
        await SendOkAsync(MapToResponse(result.Value), ct);
    }
}

public record ExchangeTokenResponse(
    string UserId,
    string Email,
    List<WalletInfo> Wallets
);
```
