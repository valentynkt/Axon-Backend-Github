## Dev Notes

### 80/20 Implementation Approach
- **20% Effort**: Configure HTTP client, create one service, one method
- **80% Value**: Full JWT validation delegated to Dynamic.xyz
- **Total LOC Target**: <150 lines including configuration

### Dynamic.xyz API Endpoints (Assumed)
```
POST /v1/jwt/validate
Headers: X-API-Key: {apiKey}
Body: { "token": "{jwt}" }
Response: { "valid": true, "user": {...}, "wallets": [...] }
```

### Simple Service Pattern
```csharp
public class DynamicAuthService
{
    private readonly HttpClient _httpClient;
    
    public async Task<Result<DynamicUser, Error>> ValidateTokenAsync(string jwt)
    {
        try 
        {
            var response = await _httpClient.PostAsJsonAsync("/v1/jwt/validate", new { token = jwt });
            if (!response.IsSuccessStatusCode)
                return Error.Unauthorized("Invalid token");
            
            var result = await response.Content.ReadFromJsonAsync<DynamicValidationResponse>();
            return result.User;
        }
        catch (HttpRequestException)
        {
            return Error.ServiceUnavailable("Dynamic.xyz unavailable");
        }
    }
}
```
