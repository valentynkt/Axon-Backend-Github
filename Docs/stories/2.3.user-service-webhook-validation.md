# Story 2.3: Dynamic User Service and Webhook Signature Validation

## Status
Draft

## Story
**As a** backend developer integrating with Dynamic.xyz user data and webhooks,  
**I want** a user service for retrieving user profiles and a secure webhook signature validator,  
**so that** I can fetch user data safely and validate webhook authenticity using HMAC-SHA256 signatures.

2. Implement `DynamicUser` and `DynamicWallet` models with read-only collections for API responses
3. Create `IWebhookSignatureValidator` interface and implementation using constant-time comparison
4. Implement HMAC-SHA256 signature validation supporting multiple signature formats (hex, base64)
5. Use `IDynamicApiClient` from Story 2.1 for all HTTP calls with proper error handling
6. Map Dynamic.xyz API response models to domain models with proper null safety
7. Implement `GetUserByIdAsync` method calling Dynamic.xyz users endpoint
8. Add comprehensive signature validation with replay attack protection considerations
9. Register all services with appropriate DI lifetimes in the infrastructure module
10. Build passes with comprehensive error handling and security best practices

### Webhook Signature Validation Requirements
[Source: FRD S2 Section 9.1, Webhook Signature Validator]

**Security Specifications:**
- Algorithm: HMAC-SHA256 using WebhookSecret from configuration
- Constant-time comparison using `CryptographicOperations.FixedTimeEquals`
- Multiple signature format support for Dynamic.xyz compatibility
- Input validation: null/empty payload and signature rejection
- Exception handling: All cryptographic exceptions logged and return false

**Signature Format Handling:**
```csharp
// Support these Dynamic.xyz signature formats:
// 1. "sha256=abc123..." (hex with prefix)
// 2. "abc123..." (base64 format)  
// 3. "def456..." (raw hex without prefix)

if (signature.StartsWith("sha256=", StringComparison.OrdinalIgnoreCase))
{
    var hex = signature.Substring(7);
    providedHash = Convert.FromHexString(hex);
}
else if (signature.Contains("=") && !signature.Contains(" "))
{
    providedHash = Convert.FromBase64String(signature);
}
else
{
    providedHash = Convert.FromHexString(signature);
}
```

### Security Best Practices
[Source: FRD S2 Section 9.1, Security Implementation]

**Constant-Time Comparison:**
- Use `CryptographicOperations.FixedTimeEquals()` to prevent timing attacks
- Never use string equality or byte-by-byte comparison for signatures
- Log validation failures for security monitoring
- Return boolean result (no detailed failure information in response)

**HMAC-SHA256 Implementation:**
```csharp
using var hmac = new HMACSHA256(secretBytes);
var computedHash = hmac.ComputeHash(payloadBytes);
return CryptographicOperations.FixedTimeEquals(computedHash, providedHash);
```

### Error Handling Patterns
**User Service Errors:**
- API call failures mapped through IDynamicApiClient Result pattern
- User not found → mapped to appropriate Error type by API client
- JSON parsing errors → Error.Validation from API client
- Network failures → Error.External from API client with Polly retry

**Webhook Validation Errors:**
- Cryptographic exceptions → Log warning, return false (never throw)
- Invalid signature format → Log warning, return false
- Null/empty inputs → Return false immediately
- Configuration missing → Log error, return false
