# Story 1.3: Implement Get Current User API Contract

## Status
Ready for Review

## Story
**As a** frontend developer using Dynamic.xyz authentication,  
**I want** to retrieve the current authenticated user's profile and wallet information,  
**so that** I can display user details and connected wallets in the application interface.

## Acceptance Criteria

1. Create `GetCurrentUserEndpoint` at `GET /api/v1/auth/me` inheriting from `BaseIdentityQueryEndpoint`
2. Use `EmptyRequest` class for endpoints that don't require request parameters
3. Create `CurrentUserResponseDto` with comprehensive user profile and wallet information
4. Create `UserProfileDto` for detailed user profile representation using primitive types
5. Reuse existing `WalletDto` from Story 1.2 for wallet information
6. Implement JWT extraction from `Authorization: Bearer <token>` header for user identification
7. Return stub/mock response with comprehensive user profile data for S1 stage
8. Include proper OpenAPI documentation with Authorization header requirements
9. Configure endpoint with FastEndpoints GET method and proper routing
10. All code compiles with no warnings and follows established patterns from previous stories
11. **HIGH RISK**: Ensure JWT authentication consistency with Story 1.2 (Risk SEC-001 - Score 6)
12. **MEDIUM RISK**: Plan comprehensive metadata serialization testing (Risk DATA-001 - Score 4)
13. **MEDIUM RISK**: Consider user profile caching strategy for performance (Risk PERF-001 - Score 4)

### Data Model Specifications  
[Source: FRD S1 - API Contracts, Section 4.2.2 Response DTOs]

**CurrentUserResponseDto Properties:**
- `User` (UserProfileDto) - Detailed user profile information
- `Wallets` (IReadOnlyList<WalletDto>) - Connected wallets (reuse from Story 1.2)
- `SyncedAt` (DateTime) - Last data synchronization timestamp
- `SyncStatus` (string) - Current synchronization status

**UserProfileDto Properties:**
- `Id` (string) - Axon internal user identifier
- `DynamicUserId` (Guid) - Dynamic.xyz user identifier
- `Email` (string) - User's email address
- `DisplayName` (string?) - Display name (optional)
- `Username` (string?) - Username (optional)
- `FirstVisit` (DateTime?) - First visit timestamp
- `LastVisit` (DateTime?) - Last visit timestamp
- `Metadata` (IReadOnlyDictionary<string, object>) - User metadata from Dynamic.xyz
