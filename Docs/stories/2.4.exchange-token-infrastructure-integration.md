# Story 2.4: Exchange Token Endpoint Infrastructure Integration

## Status
Draft

## Story
**As a** API client sending Dynamic.xyz JWT tokens for authentication,  
**I want** the exchange token endpoint to validate real JWT tokens and return actual user data,  
**so that** I can authenticate users and retrieve their profile information with connected wallets.

1. Update ExchangeTokenEndpoint to use IJwtValidationService for real JWT validation instead of mock responses
2. Update ExchangeTokenEndpoint to use IDynamicUserService for real user data retrieval
3. Implement proper JWT extraction from Authorization header with Bearer token validation
4. Map DynamicJwtPayload and DynamicUser to ExchangeTokenResult with proper ID generation
5. Generate stable Axon user and wallet IDs using SHA256 hashing of Dynamic.xyz IDs
6. Handle all JWT validation and user service errors with appropriate HTTP status codes
7. Remove S1 stub responses and implement full end-to-end token exchange flow
8. Update endpoint configuration to require Bearer token authentication (remove AllowAnonymous)
9. Implement comprehensive error handling for invalid tokens, user not found, and service failures
10. Build passes with real Dynamic.xyz integration and proper error responses

// 1. Extract JWT from Authorization header
var authHeader = HttpContext.Request.Headers.Authorization.FirstOrDefault();
if (string.IsNullOrEmpty(authHeader) || !authHeader.StartsWith("Bearer ", StringComparison.OrdinalIgnoreCase))
    return Error.Unauthorized("Missing or invalid Authorization header");

var token = authHeader.Substring(7);

// 2. Validate JWT using infrastructure service
var jwtResult = await _jwtValidationService.ValidateTokenAsync(token, ct);
if (jwtResult.IsFailure)
    return Result.Failure<ExchangeTokenResult, Error>(jwtResult.Error);

### Axon ID Generation Requirements
[Source: FRD S2 Section 10.1, ID Generation Methods]

**Stable ID Generation Algorithm:**
```csharp
private static string GenerateAxonUserId(Guid dynamicUserId)
{
    var bytes = dynamicUserId.ToByteArray();
    var hash = SHA256.HashData(bytes);
    return $"usr_{Convert.ToBase64String(hash).Substring(0, 16)}";
}

private static string GenerateAxonWalletId(Guid dynamicWalletId)
{
    var bytes = dynamicWalletId.ToByteArray();
    var hash = SHA256.HashData(bytes);
    return $"wlt_{Convert.ToBase64String(hash).Substring(0, 16)}";
}
```

**ID Generation Requirements:**
- Must be deterministic (same input → same output)
- Use SHA256 for cryptographic strength
- Base64 encoding for URL-safe characters
- Prefix for type identification (usr_, wlt_)
- Truncate to 16 characters for reasonable length

### Error Handling Patterns
**JWT Validation Errors:**
- Invalid header format → Error.Unauthorized("Missing or invalid Authorization header")
- JWT validation failure → Pass through IJwtValidationService error (Unauthorized, etc.)
- Token expired → Error.Unauthorized("Token expired") from validation service

**User Service Errors:**
- User not found → Error.NotFound("User not found") from user service
- API failure → Error.External("Service unavailable") from user service
- Network timeout → Error.Timeout("Request timeout") from user service
