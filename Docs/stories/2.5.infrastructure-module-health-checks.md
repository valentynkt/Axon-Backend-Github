### Health Check Implementation Requirements
[Source: ASP.NET Core Health Check patterns and Dynamic.xyz integration needs]

**DynamicXyzHealthCheck Specifications:**
```csharp
public class DynamicXyzHealthCheck : IHealthCheck
{
    private readonly IDynamicApiClient _apiClient;
    private readonly IJwksKeyProvider _jwksProvider;
    
    public async Task<HealthCheckResult> CheckHealthAsync(
        HealthCheckContext context, 
        CancellationToken cancellationToken = default)
    {
        try
        {
            // 1. Check JWKS endpoint availability
            var keys = await _jwksProvider.GetSigningKeysAsync(cancellationToken);
            if (!keys.Any())
                return HealthCheckResult.Unhealthy("JWKS endpoint returned no keys");
            
            // 2. Check Dynamic.xyz API health endpoint  
            var healthResult = await _apiClient.GetAsync<object>("health", cancellationToken);
            if (healthResult.IsFailure)
                return HealthCheckResult.Unhealthy($"Dynamic.xyz API unavailable: {healthResult.Error.Message}");
            
            // 3. Return healthy with diagnostic data
            var data = new Dictionary<string, object>
            {
                ["jwks_key_count"] = keys.Count,
                ["api_status"] = "available",
                ["checked_at"] = DateTime.UtcNow
            };
            
            return HealthCheckResult.Healthy("Dynamic.xyz integration healthy", data);
        }
        catch (Exception ex)
        {
            return HealthCheckResult.Unhealthy($"Health check failed: {ex.Message}", ex);
        }
    }
}
```

### Health Check Endpoint Configuration
**Health Check Registration:**
- Name: "dynamic-xyz" for specific service monitoring
- Tags: ["ready", "external"] for categorization
- Timeout: Default (30 seconds) sufficient for external service checks
- Registration: TypeActivatedCheck for DI support

**Endpoint Routing:**
- `/health` - General health status
- `/health/ready` - Readiness probe (includes external services)
- `/health/dynamic-xyz` - Specific Dynamic.xyz health check
