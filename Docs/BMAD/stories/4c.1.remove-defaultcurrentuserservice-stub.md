# Story 4c.1: Remove DefaultCurrentUserService Stub

## Status
Draft

## Story
**As a** Backend Developer,
**I want** to remove the DefaultCurrentUserService stub completely from the Chat module and update DI registration to use Identity module's HttpContextUserService,
**so that** the Chat module leverages shared cached identity resolution infrastructure instead of hardcoded stub values, eliminating duplicate identity code and preparing for 50x performance improvement.

## Acceptance Criteria
1. Delete DefaultCurrentUserService.cs file completely
2. Remove ICurrentUserService registration from Chat module DI
3. Verify Chat module uses Identity module's service
4. No compilation errors in Chat module

### Previous Story Insights
Epic 4b completed the enhanced HttpContextUserService with 3-tier caching hierarchy in the Identity module: HttpContext.Items (0ms) → IMemoryCache (<1ms) → Database (20-50ms). Epic 4b also completed cache warming in ExchangeCredentialHandler, ensuring optimal cache population for subsequent identity resolution calls.
