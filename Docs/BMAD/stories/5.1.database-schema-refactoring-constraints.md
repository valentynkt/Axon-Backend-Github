# Story 5.1: Database Schema Refactoring & Constraint Implementation

## Status
Draft

## Story
**As a** System Architect,
**I want** to refactor the existing database schema to add environment isolation and implement the 5 critical database constraints from the PRD,
**so that** identity uniqueness, environment isolation, and ownership exclusivity are guaranteed at the database level, making violations impossible even with direct DB access.

## Acceptance Criteria
1. **Environment Model Implementation** (LOCKED decision):
   - Add `environment` column (string) to Wallet and IdentityCredential tables
   - Values: 'mainnet', 'devnet', 'test' (NOT integers)
   - Keep `chain_id` for chain only (e.g., 'solana', 'ethereum')
   - Split any encoded values like 'solana:mainnet' during migration
   - Backfill existing data with appropriate environment value
2. **5 Named Database Constraints** with CONCURRENTLY creation:
   - `ux_wallet_env_chain_addr`: (environment, chain, address) WHERE is_deleted=false
   - `ux_credential_env`: (environment, provider, issuer, subject) WHERE is_deleted=false
   - `ux_ownership_pair`: (principal_id, wallet_id) WHERE is_deleted=false
   - `ux_exclusive_signing`: (wallet_id) WHERE status='verified' AND access='signing' AND is_deleted=false
   - `ux_chain_default`: (principal_id, environment, chain) WHERE is_deleted=false
3. **Migration Deduplication** (per Epic decision #7):
   - Keep record with oldest `first_seen_at` when conflicts found
   - Move all references to survivor record
   - Generate deduplication report with affected records
4. **Query Plan Validation**:
   - Run EXPLAIN ANALYZE on all identity queries
   - Verify indexes are being used properly
   - Document query performance metrics
5. **Performance Requirements**:
   - Constraint checks add <10ms overhead
   - Bulk operations remain efficient
   - Index creation doesn't block production traffic
6. **Two-Phase Constraint Application**:
   - Create constraints with NOT VALID first
   - Backfill and fix violations
   - Run VALIDATE CONSTRAINT after cleanup

### SQL for Named Constraints
```sql
-- Use CONCURRENTLY to avoid locking tables
CREATE UNIQUE INDEX CONCURRENTLY ux_wallet_env_chain_addr
  ON identity.wallet (environment, chain_id, address)
  WHERE is_deleted = false;

CREATE UNIQUE INDEX CONCURRENTLY ux_credential_env
  ON identity.credential (environment, provider, issuer, subject)
  WHERE is_deleted = false;

CREATE UNIQUE INDEX CONCURRENTLY ux_ownership_pair
  ON identity.wallet_ownership (principal_id, wallet_id)
  WHERE is_deleted = false;

CREATE UNIQUE INDEX CONCURRENTLY ux_exclusive_signing
  ON identity.wallet_ownership (wallet_id)
  WHERE status = 'verified' AND access_mode = 'signing' AND is_deleted = false;

CREATE UNIQUE INDEX CONCURRENTLY ux_chain_default
  ON identity.principal_chain_default (principal_id, environment, chain_id)
  WHERE is_deleted = false;

-- CHECK constraints for valid values
ALTER TABLE identity.wallet
  ADD CONSTRAINT check_wallet_environment
  CHECK (environment IN ('mainnet','devnet','test')) NOT VALID;

ALTER TABLE identity.wallet
  ADD CONSTRAINT check_wallet_chain
  CHECK (chain_id IN ('solana','ethereum')) NOT VALID;

ALTER TABLE identity.credential
  ADD CONSTRAINT check_credential_environment
  CHECK (environment IN ('mainnet','devnet','test')) NOT VALID;
```

### Two-Phase Constraint Pattern
```sql
-- Phase 1: Add constraint without validation (allows existing data)
ALTER TABLE identity.wallet
  ADD CONSTRAINT check_wallet_environment
  CHECK (environment IN ('mainnet','devnet','test')) NOT VALID;

-- Phase 2: After data cleanup, validate the constraint
ALTER TABLE identity.wallet VALIDATE CONSTRAINT check_wallet_environment;

-- Same pattern for all CHECK constraints
ALTER TABLE identity.wallet VALIDATE CONSTRAINT check_wallet_chain;
ALTER TABLE identity.credential VALIDATE CONSTRAINT check_credential_environment;
```

### Migration Split & Deduplication Algorithm
```csharp
// Step 1: Split encoded chain values
var walletsToSplit = await context.Wallets
    .Where(w => w.ChainId.Contains(':'))
    .ToListAsync();

foreach (var wallet in walletsToSplit)
{
    var parts = wallet.ChainId.Split(':');
    wallet.ChainId = parts[0]; // e.g., 'solana'
    wallet.Environment = parts[1]; // e.g., 'mainnet'
}

// Step 2: Find duplicates after split
var duplicates = await context.Wallets
    .GroupBy(w => new { w.Environment, w.ChainId, w.Address })
    .Where(g => g.Count() > 1)
    .SelectMany(g => g.OrderBy(w => w.FirstSeenAt).Skip(1))
    .ToListAsync();

// Step 3: Keep oldest, update references
var dedupeReport = new List<DedupeEntry>();
foreach (var duplicate in duplicates)
{
    var survivor = await context.Wallets
        .Where(w => w.Environment == duplicate.Environment
                 && w.ChainId == duplicate.ChainId
                 && w.Address == duplicate.Address)
        .OrderBy(w => w.FirstSeenAt)
        .FirstAsync();

    // Log for report
    dedupeReport.Add(new DedupeEntry
    {
        DuplicateId = duplicate.Id,
        SurvivorId = survivor.Id,
        Environment = duplicate.Environment,
        ChainId = duplicate.ChainId,
        Address = duplicate.Address
    });

    // Update all references to point to survivor
    await MigrateReferences(duplicate.Id, survivor.Id);

    // Delete duplicate
    context.Wallets.Remove(duplicate);
}

// Step 4: Generate CSV report
await File.WriteAllTextAsync("deduplication-report.csv",
    CsvSerializer.Serialize(dedupeReport));
```

### Error Handling for Constraints
```csharp
try
{
    await repository.AddAsync(wallet);
}
catch (DbUpdateException ex) when (ex.InnerException is PostgresException pgEx)
{
    return pgEx.ConstraintName switch
    {
        "ux_wallet_env_chain_addr" => Error.Conflict(
            $"Wallet already exists on {wallet.Environment}/{wallet.ChainId}"),
        "ux_exclusive_signing" => Error.Conflict(
            $"Another verified signing owner exists on {wallet.Environment}"),
        "ux_ownership_pair" => Error.Conflict("Ownership already exists"),
        "check_wallet_environment" => Error.Validation(
            $"Invalid environment: {wallet.Environment}. Must be mainnet, devnet, or test"),
        "check_wallet_chain" => Error.Validation(
            $"Invalid chain: {wallet.ChainId}. Must be solana or ethereum"),
        _ => Error.Persistence("Database constraint violation")
    };
}
```
