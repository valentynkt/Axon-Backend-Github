# Story 1.5: `/auth/me` Query + Deterministic ETag

## Status
**Done**

## Story
**As a** frontend-facing engineer,  
**I want** `GET /auth/me` to return a snapshot with a deterministic ETag and `If-None-Match` support,  
**so that** clients rehydrate cheaply.

## Acceptance Criteria
1. **Query Handler**: `GetMyPrincipalQuery` resolves by credential
2. **ETag Fingerprint**: DB fingerprint used as ETag; **304** when `If-None-Match` matches
3. **ETag Invariants**: ETag changes only on (a) riskTier change, (b) **verified & signing** ownership add/remove, (c) chain default change
4. **No-op Protection**: Pending-only ownership changes, `last_seen` touches, and no-op writes **DO NOT** change ETag
5. **Not Found Handling**: **404** MAY be returned if no Principal exists yet (pre-exchange)

## Integration Verification
- IV1: ETag changes only on specified events
- IV2: Cache-Control set to `private, max-age=0, must-revalidate`
- IV3: No sensitive data leakage

**ETag Fingerprint Implementation** [Source: architecture.md#database-schema]:
```sql
SELECT encode(
  digest(
    COALESCE( to_char(p.updated_at, 'YYYY-MM-DD"T"HH24:MI:SS.USZ'), '' ) ||
    COALESCE( to_char(MAX(o.updated_at), 'YYYY-MM-DD"T"HH24:MI:SS.USZ'), '' ) ||
    COALESCE( to_char(MAX(d.updated_at), 'YYYY-MM-DD"T"HH24:MI:SS.USZ'), '' ),
    'sha256'),
  'hex') AS fingerprint
FROM identity.principal p
LEFT JOIN identity.wallet_ownership o ON o.principal_id = p.id AND o.status = 1 AND o.access_mode = 0
LEFT JOIN identity.principal_chain_default d ON d.principal_id = p.id
WHERE p.id = $1
GROUP BY p.id, p.updated_at;
```

**API Specification** [Source: architecture.md#rest-api-specification]:
- **Headers**: `Authorization: Bearer <JWT>`, Optional `If-None-Match: "<etag>"`
- **Response 200**: `CurrentUserResult` with `ETag` header and `Cache-Control: private, max-age=0, must-revalidate`
- **Response 304**: No body when `If-None-Match` matches server fingerprint
- **Response 404**: MAY be returned if caller has not completed successful exchange yet
- **Response 401**: Invalid/expired JWT

**CurrentUserResult Schema** [Source: architecture.md#rest-api-specification]:
```json
{
  "profile": { "axonId": "01JJ8Z3W1W0Q9QYJYF3EG2H20X", "riskTier": "medium" },
  "wallets": [
    { "walletId": "01JJ8Z3X...", "chainId": "solana", "address": "...", "accessMode": "signing", "isVerified": true }
  ],
  "chainDefaults": { "solana": "01JJ8Z3X..." }
}
```

**ETag Determinism Rules** [Source: architecture.md#domain-model]:
- **ETag MUST change**: (a) RiskTier changes, (b) verified & signing ownership add/remove, (c) chain default changes
- **ETag MUST NOT change**: Pending-only ownership changes, `last_seen` touches, no-op writes (same riskTier/defaults)
- **Privacy Protection**: Response MUST NOT include other Principal IDs or sensitive information
