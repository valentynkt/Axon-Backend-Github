# Story 1.1: EF Core Model, Configs & Initial Migration (Code-First)

## Status
Ready for Review

## Story
**As a** backend engineer,  
**I want** code-first entity models and fluent configurations (plus initial migration),  
**so that** invariants are enforced by the generated schema with no separate DB schema doc.

## Acceptance Criteria
1. Entities/VOs: Principal, Credential, Wallet, WalletOwnership, PrincipalChainDefault; ULID ids; enums (risk `low|medium|high`, access `signing|watchOnly`, status `pending|verified|revoked`).
2. Fluent configs enforce:
   - Credential unique `(provider, issuer, subject)`.
   - Wallet unique `(chain_id, address)`.
   - WalletOwnership unique `(principal_id, wallet_id)` **and** **partial unique** for one **verified & signing** owner per wallet.
   - PrincipalChainDefault composite key `(principal_id, chain_id)` with FK to a **verified & signing** wallet.
   - `updated_at` concurrency tokens on write tables.
3. ETag fingerprint implemented as compiled query combining principal/ownership/default timestamps; returns hex string.
4. Initial migration generated and applied locally (dev/test) via EF migrations.

## Integration Verification
- IV1: Namespacing confined to Identity; no collisions.
- IV2: Constraint tests (Testcontainers) validate uniqueness + partial-unique.
- IV3: Compiled queries avoid N+1 on hot paths.

### Data Models
**Domain Entities** [Source: architecture.md#120-147]:
- **AxonPrincipal**: Aggregate root with Id (ULID), Type (Human/Service), RiskTier (low/medium/high enum), collections of Credentials, WalletOwnerships, ChainDefaults
- **Wallet**: Independent aggregate with Id (ULID), ChainId (string), Address (normalized), FirstSeenAt, LastSeenAt timestamps
- **IdentityCredential**: Belongs to Principal, unique by (provider, issuer, subject)
- **WalletOwnership**: Links Principal to Wallet with AccessMode (signing/watchOnly) and Status (pending/verified/revoked)
- **PrincipalChainDefault**: Maps (principalId, chainId) to walletId for default wallet per chain

**Value Objects**:
- Address: Normalized wallet address
- RiskTier: Enum with values low(0), medium(1), high(2) - wire format uses strings
- AccessMode: Enum with signing(0), watchOnly(1)
- OwnershipStatus: Enum with pending(0), verified(1), revoked(2)

### Database Schema
[Source: architecture.md#471-537]
- Schema name: `identity`
- Tables: principal, credential, wallet, wallet_ownership, principal_chain_default
- ULID stored as CHAR(26) with BTREE indexes
- Concurrency control via updated_at TIMESTAMPTZ with EF tokens
- Critical partial unique index: `ux_wallet_verified_signing_owner` on wallet_ownership
