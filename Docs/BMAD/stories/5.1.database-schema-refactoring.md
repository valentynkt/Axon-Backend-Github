### Global Query Filter Benefits

The project already implements global query filters in `WriteDbContextBase.ApplySoftDeleteQueryFilter()` which automatically:
- Adds `WHERE is_deleted = false` to ALL queries for entities implementing `ISoftDeletable`
- Ensures partial indexes with `HasFilter("is_deleted = false")` are automatically used
- Eliminates need for manual soft delete checks in repository code
- Provides consistent soft delete behavior across all modules

**Key Implementation Details:**
```csharp
// In WriteDbContextBase.cs - already implemented
private static void ApplySoftDeleteQueryFilter(ModelBuilder modelBuilder)
{
    foreach (var entityType in modelBuilder.Model.GetEntityTypes())
    {
        if (typeof(ISoftDeletable).IsAssignableFrom(entityType.ClrType))
        {
            var filter = Expression.Lambda(Expression.Not(prop), p);
            entityType.SetQueryFilter(filter); // Automatically adds WHERE !IsDeleted
        }
    }
}
```

This means:
- Repository queries don't need manual `WHERE is_deleted = false`
- Partial indexes automatically match query conditions
- Use `IgnoreQueryFilters()` only when explicitly accessing soft-deleted records

public void Configure(EntityTypeBuilder<Wallet> builder)
