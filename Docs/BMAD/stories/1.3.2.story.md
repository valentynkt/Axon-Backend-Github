## Dev Notes

### 🚨 CRITICAL Findings from Deep Infrastructure Review

**🔥 Missing Service Registration (Runtime Failure Risk)**:
- `HttpContextUserService` implements `ICurrentUserService` from BuildingBlocks
- Used by ALL command/query handlers via base classes (`BaseIdentityCommandHandler`, `BaseIdentityQueryHandler`, etc.)
- **NOT registered in DI anywhere** - will cause `InvalidOperationException` at runtime
- Chat module uses `DefaultCurrentUserService` for the same purpose
- This is the most critical issue that must be resolved first

**🗑️ IdentityMigrationContext Should Be Removed**:
- Chat module has NO separate migration context - uses main `ChatDbContext` with `DesignTimeDbContextFactory`
- Identity's separate `IdentityMigrationContext` creates maintenance overhead and architectural inconsistency
- EF Core design-time tools work perfectly with main DbContext + factory pattern
- Removal simplifies architecture and aligns with Chat's proven approach
