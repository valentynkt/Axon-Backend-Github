### CRITICAL: Dynamic.xyz JWT Validation Specifics

**Dynamic.xyz Authentication Requirements** [Source: Current Implementation Lines 275-298]:
- **Issuer Format**: MUST be `app.dynamicauth.com/{environmentId}` (line 275)
- **Algorithm Restriction**: ONLY RS256 tokens accepted - reject all others (lines 293-298)
- **Audience Validation**: MUST be disabled - Dynamic.xyz doesn't use aud claim (line 276)
- **Claim Mapping**: MUST disable `MapInboundClaims = false` to preserve JWT claim names vs WIF mapping (line 288)
- **Clock Skew**: Configurable via `JwtValidationOptions.ClockSkewMinutes` (default 5 minutes)
- **JWKS Endpoint**: Constructed as `{baseUrl}/sdk/{environmentId}/.well-known/jwks.json`

**⚠️ BREAKING CHANGE RISK**: Any modification to these validation parameters will break Dynamic.xyz authentication.

### Polly Retry Policy Configuration Guidance

**Recommended Configuration**:
```csharp
// In DI registration
services.AddHttpClient<IJwksService, JwksService>()
    .AddStandardResilienceHandler(options =>
    {
        options.Retry = new HttpRetryStrategyOptions
        {
            MaxRetryAttempts = 3,
            BackoffType = DelayBackoffType.Exponential,
            UseJitter = true,
            Delay = TimeSpan.FromMilliseconds(500)
        };
        options.CircuitBreaker.SamplingDuration = TimeSpan.FromSeconds(10);
        options.AttemptTimeout.Timeout = TimeSpan.FromSeconds(5);
    });
```
