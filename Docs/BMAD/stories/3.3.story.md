# Story 3.3: Optimize Chain Defaults Processing to Avoid Redundant DB Operations

## Status
**Done**

## Story
**As a** developer maintaining the Identity module,
**I want** to optimize the ApplyChainDefaults processing logic to avoid redundant database operations,
**so that** the system doesn't unnecessarily process chain defaults when they already exist for existing principals.

## Acceptance Criteria

1. **Check Existing Defaults Before Processing**: Modify `ExchangeCredentialHandler.ApplyChainDefaults` to query existing chain defaults for the principal before attempting to apply new ones
2. **Skip Processing for Existing Chains**: Only process chain defaults for chains where the principal doesn't already have a default wallet set
3. **Maintain Idempotency**: Preserve the current no-op behavior when attempting to set the same default twice
4. **Performance Optimization**: Reduce unnecessary database calls and domain method invocations for existing principals with established defaults
5. **Preserve Existing Behavior**: Ensure new principals and first-time wallet linking continue to work exactly as before

**Proposed Optimized ApplyChainDefaults Method**:
```csharp
private async Task<int> ApplyChainDefaults(
    AxonPrincipal principal,
    List<WalletId> processedWalletIds,
    CancellationToken cancellationToken)
{
    // Get eligible verified+signing ownerships
    var eligibleOwnerships = principal.WalletOwnerships
        .Where(wo => processedWalletIds.Contains(wo.WalletId) &&
                    wo.Status == Domain.Enums.OwnershipStatus.Verified &&
                    wo.AccessMode == Domain.Enums.AccessMode.Signing)
        .ToList();

    if (eligibleOwnerships.Count == 0)
        return 0;

    // NEW: Get existing chain defaults to filter out chains that already have defaults
    var existingDefaultChains = principal.ChainDefaults
        .Where(cd => !cd.IsDeleted)  // Only active defaults
        .Select(cd => cd.ChainId)
        .ToHashSet();

    // Get wallet details to determine chain mappings
    var wallets = await _walletRepository.GetByIdsAsync(
        eligibleOwnerships.Select(o => o.WalletId),
        cancellationToken);

    // NEW: Filter to only chains that don't already have defaults
    var chainGroups = wallets
        .GroupBy(w => w.ChainId)
        .Where(cg => !existingDefaultChains.Contains(cg.Key))  // Skip chains with existing defaults
        .ToList();

    int defaultsApplied = 0;
    int chainsSkipped = existingDefaultChains.Count;

    // Log optimization metrics
    _logger.LogDebug("Chain defaults processing: {ChainsToProcess} chains to process, {ChainsSkipped} chains skipped (already have defaults)",
        chainGroups.Count, chainsSkipped);

    // Rest of processing remains the same...
}
```

**Expected Performance Benefits**:
- Fewer database queries for wallets when most chains already have defaults
- Reduced domain method invocations
- Better performance for existing principals with established defaults
- Maintains exact same behavior and results
