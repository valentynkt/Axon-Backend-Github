# Business Context - Axon AI Principles

## Core Mission ⚡
**Solana Co-Pilot**: Eliminate Web3 complexity through safety-first, non-custodial AI that translates user intent into secure on-chain actions.

## The 7 Principles ⚡

| # | Principle | Development Impact |
|---|-----------|-------------------|
| 1 | **Pioneer Relentlessly** | Build entirely new paradigms, not incremental improvements |
| 2 | **Conquer Complexity** | Every feature must reduce cognitive load |
| 3 | **Ship at Lightspeed** | Rapid, focused releases over monolithic perfection |
| 4 | **Safety is the Engine** | Rigorous transaction simulation, human-readable outcomes |
| 5 | **User is Sovereign** | Never hold keys/custody, user always in control |
| 6 | **Build for Builders** | Provide elegant API, solve developer pain points |
| 7 | **Evolve to DAO** | Infrastructure becomes decentralized public good |

## Value Alignment ⚡
- **Utility-as-a-Service**: B2B infrastructure layer for Solana ecosystem
- **Intelligence + Action**: Memory (insights) + Hands (execution)  
- **Force Multiplier**: Enable every dApp to have world-class AI layer

## Development Principles ⚡
- **Research-First**: Always validate build vs buy decisions
- **Safety-First**: Simulation and verification before execution
- **User-Sovereign**: Non-custodial architecture patterns
- **Ecosystem-Native**: Designed specifically for Solana builders
